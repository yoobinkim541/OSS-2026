# OpenCV 1강 — 이미지 배열, 회색조, 블러, Canny

이 수업의 목표는 사진을 로봇 경로로 바꾸기 전에 OpenCV가 사진을 어떤 데이터로 보고, 엣지 검출 파라미터가 결과를 어떻게 바꾸는지 이해하는 것이다.

## 핵심 개념

- OpenCV에서 컬러 사진은 보통 NumPy 배열이며 모양은 높이 × 너비 × 채널 수다. 컬러 픽셀의 채널 순서는 RGB가 아니라 BGR이다.
- 회색조 사진은 높이 × 너비의 2차원 배열이며, 각 픽셀은 보통 0~255 밝기값이다.
- 이미지 배열에서 첫 번째 인덱스는 행(y), 두 번째는 열(x)이다. 로봇의 Y/Z 좌표와는 방향 및 단위가 다르므로 나중에 별도 변환해야 한다.
- Gaussian blur는 작은 밝기 변화를 누그러뜨려 Canny가 센서 노이즈나 질감에 과민하게 반응하는 일을 줄일 수 있다. 너무 강하게 흐리면 원하는 세부도 사라진다.
- Canny는 밝기 변화가 큰 위치를 선 후보로 표시한다. 낮은 임계값/높은 임계값을 바꾸면 결과 선의 양과 연결성이 바뀐다. Canny 결과는 아직 로봇이 그릴 경로가 아니다.

OpenCV 공식 기본 영상 문서는 BGR 채널 순서와 배열 모양을 설명하고, Canny 문서는 먼저 Gaussian 필터로 노이즈를 줄인 뒤 두 임계값을 사용한다고 설명한다. [기본 영상 연산](https://docs.opencv.org/4.5.3/d3/df2/tutorial_py_basic_ops.html), [Canny 설명](https://docs.opencv.org/4.10.0/da/d22/tutorial_py_canny.html)

## 실습 코드

파일: lesson-01.py

먼저 WSL2에서 OpenCV가 현재 Python에 설치되어 있는지 확인한다.

    python3 -c "import cv2; print(cv2.__version__)"

그 다음 프로젝트 폴더를 현재 디렉터리로 두고 사진 경로를 인자로 전달한다.

    python3 docs/opencv-study/lesson-01.py /사진/경로/sample.jpg

출력 폴더는 기본값 opencv_lesson1_output이다. 원하는 위치를 주려면 다음과 같이 실행한다.

    python3 docs/opencv-study/lesson-01.py /사진/경로/sample.jpg --out opencv_lesson1_output

이 스크립트는 원본 배열의 크기와 자료형을 출력하고, 회색조, 블러, 두 가지 Canny 설정의 이미지를 각각 저장한다. 마지막 비교 이미지는 회색조/블러/약한 임계값/강한 임계값 순서다. 임계값 50/120과 100/200은 학습용 출발값이며 최종 프로젝트 설정값으로 확정한 것은 아니다.

## 직접 관찰할 질문

1. 사진의 배열 크기와 채널 수는 얼마인가? 회색조로 바꾸고 나면 배열 모양이 어떻게 바뀌는가?
2. Gaussian blur 뒤에 사라진 선이나 점이 있는가?
3. 낮은 임계값 결과와 높은 임계값 결과 중 원하는 대상의 윤곽이 더 잘 이어진 쪽은 어느 쪽인가?
4. 배경 질감이나 그림자에서 원하지 않는 엣지가 얼마나 생기는가?

관찰 결과는 다음 단계에서 기준 이미지와 CV 파라미터를 정할 때 사용한다. 필요하면 같은 실습을 물체 사진, 인물 사진, 일러스트에 각각 적용해 입력 종류별 차이를 비교한다.
