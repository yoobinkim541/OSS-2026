# 2026-09-26 — 입력 이미지를 컬러 원본으로 표시

## 문제
- **증상:** GUI의 "입력" 칸과 에이전트의 `view(original)`이 흑백 이미지를 보여 줬습니다. 선 검출용으로 흑백 변환한 이미지(`base`)를 그대로 화면에 썼기 때문입니다.
- **추가 문제:** 이미지를 열어도 "처리 실행" 전에는 입력 칸이 비어 있었습니다.

## 해결
- **`sketch_pipeline.load_color()`:** 흑백과 같은 크기(긴 변 800px)로 컬러 원본(BGR)을 읽습니다. 크기가 같아서 획 좌표를 원본 위에 그대로 겹칠 수 있습니다.
  - 투명 PNG는 흰 배경에 합성하고, 16비트 이미지는 8비트로 바꿉니다.
- **세션:** `SketchSession.color`에 원본을 저장합니다. `result["color"]`와 `render("original")`은 컬러 원본을 돌려주고, 선 검출은 지금처럼 흑백으로 합니다.
- **GUI:** 이미지를 열자마자 입력 칸에 컬러 원본을 표시합니다(`_show_original`). 처리 후에도 입력 칸은 컬러로 보입니다.
- **에이전트:** 도구 설명에 original이 컬러 원본이고, 처리 자체는 흑백으로 한다고 적었습니다. 이제 LLM도 색을 보고 판단할 수 있습니다.

## 확인
- **자동 테스트:** 원본이 3채널이고 흑백과 크기가 같은지, 투명 PNG가 흰 배경으로 합성되는지 확인하는 테스트를 추가했습니다(전체 76개 통과).
- **화면 확인:** GUI 미리보기를 이미지로 저장해 illust1이 컬러로 보이는 것을 확인했습니다.

## 다음
