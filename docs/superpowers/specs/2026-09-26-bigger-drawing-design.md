# 더 크게 그리기 (도달 범위 기반 비대칭 영역)

설계 문서 · 2026-09-26

## 1. 배경과 목표
- **지금:**
  - 실행기가 허용하는 범위는 실물로 확인된 ±50mm(100×100mm)입니다.
  - "넓은 범위"(실물 미확인)는 ±60mm입니다.
  - 긴 변 100mm로 그리면 선이 촘촘해 펜 굵기(0.5mm) 때문에 뭉개집니다. 전신 사진은 얼굴이 9~21mm밖에 안 됩니다.
- **도달 지도 (시뮬레이터, 자세 고정, 종이 중심 = 호밍 TCP):**
  - 좌우 ±150, 아래 −110mm까지는 여유가 충분합니다.
  - 위쪽은 B(J5)가 30° 한계에 걸립니다. 가운데는 +60mm까지 여유가 7°이고, 좌우로 갈수록 낮아져 ±135mm에서는 +42.5mm입니다.
- **목표:** "넓은 범위"를 도달 지도에 맞춘 **지붕 모양 영역**으로 바꿔 더 크게 그리게 합니다.
  - 가로로 넓은 그림: 약 250×127mm (지금 넓은 범위의 약 2.2배)
  - 정사각형: 약 140×140mm
- **사용자 결정 (2026-09-26):** 로봇을 쓸 수 없어 실물 확인은 나중에 하고, 나머지는 진행합니다.
- **범위:** 영역은 계속 "실물 미확인"으로 둡니다. 로봇으로 그릴 때 넓은 범위 허용을 체크해야 쓸 수 있고, 실물로 확인된 ±50mm는 그대로입니다.

## 2. 영역 정의 (`drawing_config.json`의 `limits_pending_verification`)
- **새 형식:**
  - `x_max_mm`: 125 (좌우 대칭)
  - `y_min_mm`: −85
  - `roof_mm`: `[[|x|, 위쪽 y], ...]`. 가로 위치별 위쪽 한계이고, 점 사이는 직선으로 잇습니다.
- **roof 값:** 도달 지도(2.5mm 격자)에서 관절 최소 여유 7° 이상인 위쪽 한계에서 2.5mm를 뺀 값입니다.
  - (0, 57.5) (50, 57.5) (60, 55) (80, 55) (90, 52.5) (100, 50) (110, 47.5) (120, 45) (125, 42.5)
- **종이 안전 여백 20mm 안:** A4 가로는 ±148.5 × ±105mm이므로 x ≤ 128.5, y ≥ −85입니다.
- **예전 형식(`max_abs_paper_x_mm`, `max_abs_paper_y_mm`)도 계속 읽습니다.** 대칭 사각형으로 취급하고, 실물 확인된 `limits`(±50)는 이 형식 그대로 둡니다.
- **설치판 이전:** 사용자 폴더 설정의 넓은 범위가 예전 기본값(±60, 사용자가 손대지 않음)이면, 읽을 때 새 기본 영역으로 바꿉니다.

## 3. 코드
- **`limits.py` `Region`:**
  - `from_cfg(dict)`
  - `contains(x, y)`
  - `top(|x|)`
  - `outline()`: 미리보기용 다각형
  - `fit(w, h)`: 그림 상자 w×h를 둘 중심 (0, cy)
    - 종이 중심(0, 0)에 들어가면 그대로 두고, 아니면 가장 적게 아래로 내립니다.
    - 어디에도 들어가지 않으면 None
  - `max_scale(w, h)`: 들어가는 최대 배율
- **실행기:** `check_limits`가 `Region.contains`를 씁니다.
- **종이 배치:** `pixels_to_paper(..., region=)`가 긴 변 box_mm로 맞춘 그림이 영역에 들어가지 않으면 아래로 옮깁니다. 그래도 안 되면 들어갈 만큼 줄입니다.
  - `transform`에 `ox`, `oy`(mm)를 추가합니다.
  - 세션의 mm↔px 변환은 이 이동을 반영합니다.
  - 100mm 이하(±50 안)는 지금과 같이 가운데에 둡니다(결과 동일).
- **세션:** box_mm 상한은 `2 × x_max`(250)입니다. 그림 크기 요약은 실제로 들어간 크기를 보여 줍니다.
- **미리보기·화면:**
  - 종이 미리보기에 실물 확인 범위(파란 사각형)와 넓은 범위(주황 지붕 모양)를 점선으로 그립니다.
  - "±60mm" 문구를 "넓은 범위(실물 미확인)"로 바꿉니다.

## 4. 확인
- **단위 테스트:** 영역 판정, 예전 형식 읽기, fit(가운데 유지·아래로 이동·축소), 설정 이전, 배치 이동 뒤 mm↔px 왕복, 100mm 결과 불변
- **시뮬레이터 안전 테스트:** 영역 테두리와 내부 격자를 실행기와 같은 계획으로 시뮬레이션합니다. IK 실패와 관절 한계 초과가 없고, 최소 여유가 5° 이상이어야 합니다.
- **실제 그림:** illust1을 긴 변 250mm로 배치해 영역 안에 들어가고 시뮬레이션이 PASS인지 확인합니다.
- **실물 확인 (나중에, 로봇이 있을 때):** 공중 모드(`--air`)로 영역 테두리 시험 경로를 그린 뒤 펜을 대고 그립니다. 이상이 없으면 `limits`를 넓힙니다.
