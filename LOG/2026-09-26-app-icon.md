# 2026-09-26 — 앱 아이콘 교체

## 변경
- 사용자가 준 그림(흰 배경 위 둥근 사각형 아이콘: 이젤에 그림을 그리는 로봇팔)을 새 앱 아이콘으로 바꿨습니다. 원본은 `assets/app_icon_source.webp`에 두었습니다.
- `assets/make_icon.py`를 "코드로 그리는 아이콘"에서 "원본에서 잘라내는 스크립트"로 바꿨습니다.
  - 흰색에서 충분히 먼(색이 진한) 픽셀 범위로 둥근 사각형을 찾습니다. 원본 1024px 중 (128, 128)–(896, 896), 768px입니다.
  - 모서리 반지름은 대각선 측정값(한 변의 약 20.3%, 156px)입니다. 4배 크기로 둥근 사각형 마스크를 그려 바깥의 흰 배경과 번짐을 투명하게 했습니다.
  - 출력: `app_icon.png`(1024), `app_icon_256.png`, `app_icon.ico`(16~256px 7종). 앱이 쓰는 `mirobot_sketch/data/`에도 복사합니다.
- 창·작업표시줄 아이콘(`gui.py`), exe 아이콘(PyInstaller spec), 설치 프로그램(`installer.iss`), 바로가기(`create_shortcuts.ps1`)가 모두 같은 파일을 가리키므로 코드는 바꾸지 않았습니다.

## 확인
- 투명 확인: 모서리 알파 0, 가운데 255, 가장자리는 부드럽게 줄어듭니다.
- 어두운/밝은 배경 위 256·64·48·32·16px 미리보기에서 흰 테두리 없이 깔끔함을 확인했습니다.
- 전체 테스트가 통과했습니다.
- 바로가기와 설치판 아이콘은 exe를 다시 빌드하거나 바로가기를 다시 만들어야 바뀝니다. Windows 아이콘 캐시 때문에 바탕화면 아이콘은 조금 늦게 바뀔 수 있습니다.
