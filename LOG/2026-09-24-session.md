# 2026-09-24 세션 — 하트 드로잉 및 종이 면 접촉 보정

시간대: Asia/Seoul (KST). 분 단위 시각을 확인할 수 없는 관찰은 날짜만 기록.

## 프로젝트/장비 기준

- 수업 텀프로젝트: 사진 입력 → 선 정리 → WLKATA Mirobot 펜 드로잉.
- 작업면: A4 용지를 가로 방향으로 벽에 고정. 도형 중심은 종이 중심에 정렬.
- 좌표 해석: 종이 위 경로는 로봇 Y-Z 평면을 사용하고, 벽 방향 법선은 로봇 X축으로 다룸.
- 앞선 세션에서 사용자가 보고한 환경: Windows에서 COM9/pyserial로 실물 제어, WSL2 Ubuntu 22.04에서 ROS 2 Humble/MoveIt2 사용. USB 패스스루된 WSL2 CH340은 응답 읽기 문제가 있어 실물 직렬 제어를 Windows에서 수행.
- 앞선 실측 기준: 새 시리얼 포트를 열면 보드가 리셋될 수 있어 연결을 재사용. 상태 조회는 ?; 관절 G-code와 펜 궤적 명령은 기존 제어 파일 및 설계 문서 참조.

위 환경/실측 항목은 앞선 사용자 제공 기록을 옮긴 것이며, 이번 로그 작성 작업에서 다시 하드웨어 검증한 내용은 아님.

## 하트 템플릿 및 가장 최근 실행 기록

도형 데이터는 trajectories/shape-library.json에 보관.

- 도형: 종이 중심 기준 70 × 60 mm 하트 윤곽, 57개 경로 점.
- 중심: 도형 경계 상자 중심을 종이 중심에 맞춤.
- 최근 실행 기록(저장된 컨트롤러 이력): 57점/56개 윤곽 이동, ACK를 받으며 연속 전송, 윤곽 속도 300 mm/min, RPY=(0,0,0), 완료 후 종이 중심 복귀, 컨트롤러 Idle.
- 기록된 중심 TCP: X=198.668, Y=0, Z=230.477 mm. 실행 명령에서는 윤곽 내 X 변화량을 0으로 두었음.
- 펜 업 간격 2.5 mm는 후퇴(clearance) 값이며, 펜 압력을 더한 값이 아님. 기준 대비 펜다운 X 압력 변화는 0 mm로 기록됨.
- 마지막 상태 조회 기록: 중심 위치에서 Idle, TCP=(198.668, 0, 230.477) mm, RPY=(0,0,0). 이 값은 중심의 로봇 TCP 상태이며 종이 전체의 접촉 보정을 입증하지 않음.
- 물리적으로 선이 균일하게 완성됐는지에 대한 최신 실행의 사진 검증은 미완료.

## 관찰된 문제

- 사용자는 마찰 때문에 펜 위치가 조금씩 움직이고, 일부 위치에서 점처럼 찍히거나 선이 끊기는 현상을 보고함.
- 사용자는 종이의 어떤 부분에서는 펜이 벽/종이에 너무 붙고, 다른 부분에서는 살짝 뜨는 듯하다고 보고함.
- 이전 사진 검토 기록에는 하트 흔적이 보이지만 선이 고르지 않고 끊김/겹침이 있어, 펜 정렬과 접촉 상태를 추가 확인해야 한다고 남아 있음.
- 눌리는 영역과 뜨는 영역이 화면 기준으로 어디인지는 아직 기록되지 않음. 사용자에게 위치 관찰을 요청했으며, 본 로그 작성 시점에는 답을 받지 못함.

## 확인된 사실과 원인 가설

### 확인된 사실

- 가장 최근 경로는 명령상 X를 고정하고 Y/Z를 따라 이동했음.
- 로봇의 중심 TCP는 X=198.668 mm로 복귀했고 Idle 상태였음.
- 사용자가 실제 종이에서 위치별 접촉 차이와 마찰에 따른 펜 이동/점찍힘을 관찰함.
- 중심의 고정 X 명령만으로 전체 종이 면의 균일 접촉이 보장되지는 않음.

### 아직 검증되지 않은 원인 가설

- 종이 면이 로봇의 Y-Z 이동면과 완전히 평행하지 않거나 종이가 부분적으로 휘어져 위치별 법선 거리가 달라질 수 있음.
- 펜 홀더 안에서 펜이 미끄러지거나, 팔/홀더가 하중에 따라 휘고 유격이 생길 수 있음.
- 정지-재시작은 점찍힘을 악화시킬 수 있음. ACK 기반 연속 전송을 사용한 기록은 있으나 최신 실행의 선 품질 사진 검증은 끝나지 않아 개선 여부를 단정하지 않음.

## 다음 작업: 종이 평면 및 펜 접촉 보정

1. 종이와 로봇 받침을 움직이지 않도록 고정하고, 펜 홀더 안의 펜 미끄러짐을 먼저 확인한다.
2. 종이 중심과 네 모서리 부근(총 5점)에서 동일한 기준의 가벼운 펜 접촉 위치를 관찰·기록한다. 측정 전에는 큰 X 이동을 적용하지 않는다.
3. 각 지점의 Y, Z 위치와 접촉 X를 기록한다. 세 점 이상으로 평면 보정을 계산하고 다섯 점으로 잔차/비평면성을 확인한다.
4. 보정 모델 X_contact = a·Y + b·Z + c를 시험 경로에 적용한다. 계수와 부호는 실제 측정 후 결정하며 현재는 미정.
5. 작은 사각형 또는 짧은 선으로 접촉 균일성을 검증한 뒤에만 전체 하트를 다시 실행한다.
6. 마찰에 의한 펜 미끄러짐이 계속되면 먼저 홀더의 기계적 고정과 종이 뒤 얇고 부드러운 받침을 점검한다. WLKATA 사용 설명서도 드로잉 시 종이 뒤 부드러운 받침과 가벼운 펜 접촉 조정을 안내함: https://uploads-ssl.webflow.com/5edc22ea8e58c13e2883e09b/5efd245acdbcfb27deb727ce_WLKATA%20Mirobot%20User%20Manual%20V1.2.pdf
