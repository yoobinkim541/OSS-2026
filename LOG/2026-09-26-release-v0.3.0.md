# 2026-09-26 — v0.3.0 릴리스

v0.2.0 이후 main에 들어간 PR #6~#9를 묶은 릴리스입니다.

## 새 기능
- **선 스무딩** (#6): "⑧ 스무딩·단순화" 단계에서 픽셀 계단과 지그재그를 없앱니다. 모서리 둥글리기는 뾰족한 끝을 자르지 않습니다.
- **얼굴 섬세하게** (#7): 실사 사진에서 OpenCV YuNet으로 얼굴을 찾습니다.
  - **자동 구도:** 종이 위 얼굴이 25mm보다 작으면 원본 해상도에서 상반신으로 자릅니다.
  - **얼굴 세밀 단계:** 얼굴만 원본 해상도로 다시 처리하고, 펜 굵기에 맞춰 촘촘한 선을 합칩니다.
- **RViz 3D 환경 설치 도우미** (#8): GUI 버튼, `mirobot setup-rviz`, 설치 프로그램 선택 항목으로 WSL2 + ROS 2 Humble + Mirobot 모델을 갖춥니다.
  - 이 릴리스부터 미리 만든 이미지(`MirobotSketch-ROS-humble-0.3.0.tar.gz`, 약 400MB)가 함께 올라갑니다.
  - 기존 WSL 배포판은 건드리지 않고, 비밀번호를 받지 않습니다.
- **더 크게 그리기** (#9): 실물 확인 전 넓은 범위를 도달 지도에 맞춘 지붕 모양 영역으로 바꿨습니다.
  - 최대 250mm까지 그릴 수 있습니다(예: 가로 사진 224×132mm).
  - 실물 확인 범위 ±50mm와 "넓은 범위 허용" 체크는 그대로입니다.
