# 얼굴 섬세하게 그리기 (자동 구도 + 얼굴 세밀 처리)

설계 문서 · 2026-09-26

## 1. 배경과 목표

- **문제:** 사진 속 얼굴이 뭉개집니다.
  - 파이프라인은 긴 변 800px로 줄인 이미지로 선을 찾습니다. 전신 사진은 얼굴이 60~110px밖에 안 돼서 눈·코·입이 몇 px로 줄어듭니다.
  - 종이 크기도 한계입니다. 긴 변 100mm로 그리면 전신 사진의 얼굴은 13~21mm입니다. 여기에 선을 더 넣으면 0.5mm 펜 선이 겹쳐 검은 덩어리가 됩니다(실험 확인).
- **목표:** 실사 사진의 얼굴이 종이 위에서 알아볼 수 있게 섬세하게 그려지게 합니다. 사용자가 따로 설정하지 않아도 자동으로 동작합니다.
- **사용자가 정한 것:**
  - 대상은 실사 사진입니다. 애니 그림은 자동 검출이 안 되므로 지금처럼 처리합니다.
  - 방식은 A(얼굴 세밀 처리)와 B(얼굴 중심 구도)를 함께 씁니다.
  - 구도는 자동으로 고릅니다.
- **실험 결과 (YuNet, 샘플 6장):**
  - 사진 3장은 모두 검출됐습니다(신뢰도 0.78~0.93, 옆얼굴 포함).
  - 애니 그림 3장은 검출되지 않았습니다(기준 0.6).

## 2. 얼굴 검출 (`mirobot_sketch/faces.py`)

- **모델:** OpenCV `FaceDetectorYN`(YuNet)
  - 모델 파일 `mirobot_sketch/data/face_detection_yunet_2023mar.onnx`(232,589바이트, SHA256 `8f2383e4…2552fa4`, MIT 라이선스, opencv_zoo)를 저장소와 exe에 포함합니다.
  - 라이선스 표기는 `THIRD_PARTY_NOTICES.md`에 넣습니다.
- **`detect_faces(bgr) -> [Face]`**
  - `Face(box=(x, y, w, h), landmarks=5×2, score)`이고, 좌표는 넣은 이미지 기준입니다.
  - 긴 변 800px 이하로 줄여서 검출하고, 좌표는 원래 크기로 되돌립니다.
  - 신뢰도 기준은 0.7이고, 신뢰도 순으로 돌려줍니다.
  - 모델 파일이 없거나, OpenCV에 `FaceDetectorYN`이 없거나, 오류가 나면 `[]`를 돌려줍니다(얼굴 없음과 같음).
  - OpenCV 5의 "Targets are not supported" 경고는 검출하는 동안 로그 수준을 낮춰 감춥니다.
- **작은 오검출은 버립니다:** 얼굴 폭이 이미지 짧은 변의 3% 미만이면 무시합니다. 무대 조명 같은 것이 신뢰도 0.3~0.6으로 잡혔기 때문입니다.

## 3. B — 구도 (① 원본 단계의 `frame`)

- **선택지:** `auto`(자동, 기본) / `full`(전체) / `bust`(상반신) / `face`(얼굴)
- **자르기는 원본 해상도에서 먼저 합니다.** 그 뒤 긴 변 800px로 맞춥니다. 배경 제거(rembg)를 켰으면 rembg 결과(원본 크기, 캐시됨)를 자릅니다.
- **자르는 틀** (얼굴 상자 w×h, 중심 cx):
  - `bust`: 폭 = 3.5w, 높이 = 1.25 × 폭(세로 4:5), 위쪽 = 얼굴 위 − 0.6h, 가로 중심 = cx
  - `face`: 한 변 = 1.8 × max(w, h)인 정사각형, 중심 = 얼굴 중심
  - 틀이 이미지 밖으로 나가면 안쪽으로 밀어 넣습니다. 틀이 이미지보다 크면 이미지 크기로 줄입니다.
- **`auto` 규칙:**
  - 전체로 그렸을 때 종이 위 얼굴 크기 = `box_mm × 얼굴 높이 / 이미지 긴 변`
  - 25mm 이상이면 `full`, 미만이면 `bust`입니다(bust 결과가 full보다 작아지는 경우는 full).
  - 얼굴이 없거나 2개 이상이면 `full`입니다.
- **얼굴이 없는데 `bust`/`face`를 고르면** `full`로 처리하고 알림을 띄웁니다.
- **알림:**
  - "자동 구도: 상반신 (전체로는 얼굴이 21mm)"
  - "얼굴을 찾지 못해 전체로 그립니다"
- **캐시와 편집:**
  - 입력 캐시 키에 실제 적용된 자르기 틀을 넣습니다. 그래서 `auto`에서 box_mm이 바뀌어 틀이 바뀌면 다시 계산합니다.
  - 실제 틀이 바뀌면 좌표계가 달라지므로 편집 기록·제안·되돌리기 기록을 비우고 알립니다(이미지를 새로 열 때와 같음).

## 4. A — 얼굴 세밀 처리 (새 단계 `face` "얼굴 세밀")

- **위치:** "이어 붙이기" 다음, "스무딩·단순화" 앞. 단계는 10개가 되고, `stage_title`에 ⑩을 추가합니다.
- **입력:** 세션이 입력을 만들 때 함께 넘깁니다.
  - `faces`: 작업 이미지(800px) 좌표의 얼굴들
  - 얼굴마다 원본 해상도 자른 이미지와 좌표 변환(배율, 원점)
- **처리 (얼굴마다):**
  1. **영역:** 얼굴 상자를 가로 1.3배, 세로 1.4배로 넓힌 타원입니다(이마·턱선 포함).
  2. **재처리:** 원본에서 그 영역의 경계 상자를 잘라 긴 변 500px로 맞춥니다. 전처리 → 선 검출 → 뼈대·획 → 겹침 제거 → 이어 붙이기를 다시 돌립니다.
     - 설정은 전체 설정을 따르되 Canny 하한·상한에 `face_sensitivity`(기본 0.6)를 곱합니다.
     - 최소 덩어리는 배율에 맞춥니다.
  3. **되돌리기:** 결과를 작업 좌표(소수)로 되돌립니다.
  4. **교체:** 전체 획 중 타원 안 부분은 지우고, 얼굴 획 중 타원 안 부분만 더합니다. 경계를 지나는 획은 경계에서 잘라 나눕니다.
  5. **밀도 제한:**
     - 펜 굵기 px = `pen_mm / (box_mm / 작업 이미지 긴 변)`
     - 얼굴 획에 펜 굵기 거리로 겹침 제거를 합니다.
     - 펜 굵기의 3배보다 짧은 획은 버립니다. 단, 눈·코·입 점(5개) 반경 `0.2 × 얼굴 폭` 안은 버리지 않습니다.
- **조절 항목:**
  - `face_detail`: 얼굴 세밀 처리, bool, 기본 켬
  - `face_sensitivity`: 얼굴 선 민감도, 0.3~1.0, 기본 0.6. 낮을수록 약한 선도 잡습니다.
  - `pen_mm`: 펜 굵기, 0.2~1.5mm, 기본 0.5
- **캐시:** 이 단계는 `box_mm`(⑩ 단계 설정)에도 의존합니다. `Stage`에 `deps=("box_mm",)`를 추가하고, 캐시 키에 포함합니다.
- **얼굴이 없거나 끄면** 입력을 그대로 넘깁니다. 결과는 지금과 똑같습니다.
- **미리보기:**
  - 획을 색별로 그리고, 얼굴 타원은 초록 윤곽, 눈·코·입 점은 초록 점으로 표시합니다.
  - 얼굴이 없으면 "얼굴을 찾지 못함" 문구를 표시합니다.
- **버린 조각:** 교체로 지운 원래 획은 `discarded_face`로 남깁니다. 기존처럼 살리기 후보가 됩니다(이유: "얼굴 세밀 처리로 교체").

## 6. 테스트와 확인

- **단위 테스트 (가짜 검출기 주입):**
  - 구도 틀 계산: bust·face 모양, 이미지 밖으로 나가는 경우, 이미지보다 큰 틀
  - `auto` 규칙: 25mm 기준, 얼굴 0개·2개, box_mm 변화
  - 얼굴 단계: 타원 안 교체, 경계 자르기, 얼굴 없음/끔이면 입력과 동일
  - 밀도 제한: 펜 굵기를 키우거나 종이를 줄이면 얼굴 획이 줄어듦, 눈·코·입 근처 짧은 획은 남음
  - `box_mm`만 바꿔도 얼굴 단계가 다시 계산됨
  - 모델 파일이 있고 불러와짐. 모델이 없으면 `[]`
  - 편집 기록은 실제 구도 틀이 바뀔 때만 비워짐
- **실제 사진 (저장소 밖 `input/`, 있을 때만):**
  - photo1~3이 검출되고, auto가 photo1=전체, photo2·3=상반신을 고르는지
  - 애니 3장은 얼굴 없음
- **전체 테스트, pyflakes, 골든 기준값:** 사진이 아닌 합성 이미지는 결과가 같아야 합니다.
- **눈으로 확인:** photo1~3 전후 비교(확대, 종이 크기)를 LOG에 남깁니다.
